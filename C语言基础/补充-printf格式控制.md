# 补充 printf 格式控制：宽度、补零、对齐

接在 [[01-变量运算与IO]] 的 1.4 节之后。1.4 讲的是 `%d`、`%f` 这些"打印什么类型"，这一篇讲**"打印成什么样子"**：占几格、空位补什么、靠左还是靠右。

起因：PAT「链表去重」（[[学校/13.cpp]]）要求地址打印成 `00100` 这种 5 位补零的形式。

> 本篇所有输出都在本机用 clang 实际跑过。输出用方括号 `[ ]` 框起来，是为了让你看清空格在哪里，**方括号本身不是 printf 打印的格式的一部分**。

---

## 1. 一个占位符的完整结构

```
%   -0+   5   .2   l   d
│   │     │   │    │   └─ 类型：d / f / s / c / x ……（1.4 节讲过）
│   │     │   │    └───── 长度：l / ll，配合 long（1.4 节讲过）
│   │     │   └────────── 精度：小数位数，或者"至少几位数字"
│   │     └────────────── 宽度：至少占几格
│   └──────────────────── 标志：怎么补、往哪边靠
└──────────────────────── 开头
```

除了 `%` 和类型，**中间每一段都可以省略**。平时写的 `%d` 就是全部省略的情况。

类比：printf 给每个数分配一个**格子**。

- **宽度**决定格子有多宽
- **标志**决定数字靠左还是靠右放，空出来的格子填空格还是填 0

---

## 2. 宽度：至少占几格

```c
printf("[%d]\n",  100);      // [100]
printf("[%5d]\n", 100);      // [  100]      补 2 个空格，凑够 5 格，数字靠右
```

**宽度是"至少"，不是"正好"**。数字比格子长时，原样打印，**不会截断**：

```c
printf("[%5d]\n", 123456);   // [123456]     6 位，超过 5 格，照样全打出来
```

---

## 3. 标志：空位补什么、往哪边靠

| 标志 | 作用 | 例子 | 输出 |
|---|---|---|---|
| （不写） | 靠右，左边补空格 | `%5d`, 100 | `[  100]` |
| `0` | 靠右，左边补 **0** | `%05d`, 100 | `[00100]` |
| `-` | **靠左**，右边补空格 | `%-5d`, 100 | `[100  ]` |
| `+` | 正数也打印 `+` 号 | `%+d`, 100 | `[+100]` |

`-` 和 `0` 不能一起用：往左靠时，右边补 0 会改变数值（`42000`），所以 C 规定这种情况下忽略 `0`。clang 会给出警告：

```
warning: flag '0' is ignored when flag '-' is present
```

---

## 4. 负数和补零：`%05d` 打印 -1 为什么是 `-0001`

```c
printf("[%05d]\n", 100);     // [00100]
printf("[%05d]\n", 0);       // [00000]
printf("[%05d]\n", -1);      // [-0001]
```

**负号也占宽度里的一格**，而且 0 补在负号**后面**：

```
格子:  [ 1 ][ 2 ][ 3 ][ 4 ][ 5 ]
-1  →  [ - ][ 0 ][ 0 ][ 0 ][ 1 ]
         ↑    └─ 补的 0 ─┘   ↑
       负号                 数字
```

这就是 PAT 链表题的坑：地址用 `%05d`，但"空地址"是 `-1`，套用同一个格式会打印成 `-0001`，判 WA。**-1 必须单独处理。**怎么处理，在你的 13.cpp 里自己写。

---

## 5. 精度：`.` 后面的数字

精度对不同类型的含义不一样：

| 类型 | `.n` 的含义 | 例子 | 输出 |
|---|---|---|---|
| `f` | 保留 n 位小数 | `%.2f`, 3.14159 | `[3.14]` |
| `s` | **最多**打印 n 个字符（会截断） | `%.3s`, "abcdef" | `[abc]` |
| `d` | **至少** n 位数字，不够补 0 | `%.5d`, 42 | `[00042]` |

宽度和精度可以一起用，宽度管格子，精度管内容：

```c
printf("[%8.2f]\n",  3.14159);   // [    3.14]     格子 8 格，内容保留 2 位小数
printf("[%08.2f]\n", 3.14159);   // [00003.14]     小数点也占一格
printf("[%-8.2f]\n", 3.14159);   // [3.14    ]
```

> 冷知识：`%.5d` 打印 -1 得到 `[-00001]`。精度只管"数字至少 5 位"，负号不算在内。它和 `%05d`（负号算在宽度里）的结果不一样。知道有这个区别就行，不用背。

---

## 6. 字符串也能对齐

```c
printf("[%10s]\n",  "abc");      // [       abc]
printf("[%-10s]\n", "abc");      // [abc       ]
printf("[%5s]\n",   "abcdefg");  // [abcdefg]     宽度是"至少"，不截断
printf("[%.3s]\n",  "abcdef");   // [abc]         精度才会截断
```

打印表格时常用 `%-10s`：名字靠左，后面的列就能对齐。

---

## 7. 常见场景速查

| 场景 | 写法 | 例子 → 输出 |
|---|---|---|
| PAT 5 位地址 | `%05d` | 100 → `00100` |
| 时间 时:分:秒 | `%02d:%02d:%02d` | 9, 5, 3 → `09:05:03` |
| 每个数占 3 格（[[学校/编程14.md]] 生死者游戏的输出要求） | `%3d` | 1, 4, 10 → `[  1  4 10]` |
| 保留两位小数 | `%.2f` | 3.14159 → `3.14` |
| 表格左对齐 | `%-10s` | "abc" → `[abc       ]` |
| 打印 `%` 本身 | `%%` | `printf("100%%")` → `100%` |
| 十六进制 | `%x` / `%X` / `%#x` / `%08x` | 255 → `ff` / `FF` / `0xff` / `000000ff` |

宽度也可以运行时再定，用 `*` 占位，从参数里取：

```c
printf("[%*d]\n", 6, 42);        // [    42]     等价于 %6d
```

---

## 易错点

1. **宽度是"至少"**：`%5d` 打印 123456 不会截断。只有字符串的精度 `%.3s` 才会截断。
2. **负号占一格**：`%05d` 打印 -1 是 `-0001`，不是 `-1`，也不是 `-00001`。
3. **`-` 和 `0` 同时写，`0` 被忽略**。
4. **scanf 里的宽度意思完全不同**：`scanf("%3d", &a)` 表示**最多读 3 个字符**。输入 `123456` 只会读进 `123`，剩下的 `456` 留在缓冲区里。不要把 printf 的格式照搬到 scanf 里。
5. **补零的是输出，不是变量**：`%05d` 只影响打印出来的样子，变量里存的还是 100。反过来，scanf 读 `00100` 时，`%d` 会把它当成 100 存进去。所以 13.cpp 里的地址存成 `int` 没问题，只是打印时要补回去。
