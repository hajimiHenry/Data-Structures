## 编写契约(后续续写者请遵守)

1. **接着 Henry 的既有代码盖楼**,不另起炉灶(他的链表在 `练习/10-单链表/`)。
2. 讲解 = 类比 + 内存图 + 对照表;**推导重于公式**(压缩存储、循环队列一律教"现场数数/验算",不让背公式)。
3. 每章末尾必须有**动手工程**:章节文件夹 + .h/.c 拆分 + 带勾选框的验收清单 + 边界/压线测试 + 至少一个"故意犯罪实验"(亲手制造一次事故观察症状)+ 限时**默写关卡**。
4. 看懂不算过,清单打满勾才算过——他的天敌是"流畅的错觉"。
5. 例题用 408 真题风格,解析折叠在 `<details>` 里。
