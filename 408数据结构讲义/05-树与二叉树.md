# 408·第五章 树与二叉树

> 这是 408 数据结构的心脏:选择题一年至少 2~3 道,大题(遍历、建树、哈夫曼)常驻。好消息:你需要的两样兵器已经在手——**递归**(C 教材 12 章,树的一切遍历都是它)和**循环队列**(408·03 章,层次遍历要用)。这一章新东西其实只有"树的语言"(术语+性质公式)和几个手算套路,代码部分对你是复习。

## 5.0 从链表到树:一根 next 变两根

你的链表结点:`data + next`,结构是一条线。二叉树结点:`data + left + right`,每个结点岔两条路:

```c
typedef struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;
```

**一棵树 = 根 + 左子树 + 右子树,空树是地板**——定义本身递归,所以处理它的代码天然递归。C 教材 12 章末尾那个预告,现在正式开演。

## 5.1 树的语言(术语一次记清,后面全用)

```
            A          ← 根(root):无父结点
          /   \
         B     C       ← B、C 是 A 的孩子(child),互为兄弟(sibling)
        / \     \
       D   E     F     ← D、E、F 无孩子 → 叶结点(leaf)
```

| 术语 | 含义 | 上图例子 |
|---|---|---|
| 结点的**度** | 它的孩子数 | A 度 2,C 度 1,D 度 0 |
| **树的度** | 所有结点度的最大值 | 2 |
| **层次** | 根为第 1 层,往下递增 | D 在第 3 层 |
| **高度/深度** | 最大层次 | 3 |
| 祖先/子孙 | 从根到它路径上的所有结点是它的祖先 | A、B 是 D 的祖先 |
| 有序树 | 孩子有左右次序之分 | 二叉树必有序 |

**第一条万能公式:任何树,结点数 = 边数 + 1**(每个结点除根外恰有一条向上的边)。写成度的语言:n = 1 + 所有结点的度之和。选择题给你各种度的结点个数求总数/叶子数,全靠它。

> 练手:一棵树有 4 个度2结点、3 个度3结点、其余是叶子,求叶子数。
> 边数 = 4×2+3×3 = 17,结点总数 = 18,叶子 = 18-4-3 = **11**。

## 5.2 二叉树:定义与两个明星形态

二叉树:每个结点**至多两个**孩子,且**左右有别**(只有一个孩子也要说清是左是右——这点和"度≤2的树"不同,判断题考过)。

- **满二叉树**:每层都塞满。高 h 共 2^h − 1 个结点。
- **完全二叉树**:只允许**最后一层右边缺**,其余全满——即"满二叉树从右往左、从下往上删了几个"。它是堆(第八章)的地基。

### 五大性质(全部现场可推,推导比结论重要)

1. 第 i 层至多 **2^(i−1)** 个结点。(每层翻倍)
2. 高 h 至多 **2^h − 1** 个结点。(等比求和)
3. **n0 = n2 + 1**(叶子数 = 度2结点数 + 1)。推导必须会:结点数 n = n0+n1+n2;边数 n−1 = n1+2n2(边都是孩子头顶的);两式相减即得。**此性质出题率全章第一。**
4. n 个结点的完全二叉树,高 = **⌊log₂n⌋ + 1**。(推法:高 h 的完全二叉树结点数在 [2^(h−1), 2^h−1] 区间,取对数)
5. 完全二叉树按层从 1 编号:i 的父亲 = **⌊i/2⌋**,左孩子 = **2i**,右孩子 = **2i+1**。(这就是数组存堆的全部依据)

> 配套小结论(选择题弹药):完全二叉树的度1结点数 **n1 只能是 0 或 1**;n 个结点能构成的**形态不同**的二叉树共卡特兰数 C(2n,n)/(n+1) 种(和出栈序列同源——不是巧合,中序遍历的栈行为正是它)。

### 存储

- **顺序存储**:数组按层编号存,性质 5 找亲戚。**只适合完全二叉树**——歪脖子树会浪费海量空位(高 h 的单支树要 2^h−1 个格子存 h 个结点)。
- **链式存储**:上面的 TreeNode,通用。**n 个结点有 2n 个指针域,用掉 n−1 个(每结点头顶一条边),空指针恰有 n+1 个**——这个数是线索二叉树(5.5)的饭票,直接背下:**空链域 n+1**。

## 5.3 遍历:全章的发动机

三种深度优先遍历,区别仅仅是"访问根"这个动作插在哪——**就是 C 教材 12 章例 12.1 那道"下3下2下1上1上2上3"**:

```c
void preorder(TreeNode *r)  { if(!r) return; visit(r); preorder(r->left);  preorder(r->right); }  // 根左右
void inorder(TreeNode *r)   { if(!r) return; inorder(r->left);  visit(r);  inorder(r->right);  }  // 左根右
void postorder(TreeNode *r) { if(!r) return; postorder(r->left); postorder(r->right); visit(r); }  // 左右根
```

**手算遍历序列的不出错姿势**:沿树的外轮廓逆时针画一圈(从根左侧下去、绕过所有叶子、从根右侧回来),每个结点会被这条线擦过三次——**第一次擦过记下 = 先序,第二次(从左下方绕过) = 中序,第三次(从右下方离开) = 后序**。一条线三份答案,快且不漏。

**层次遍历** = 队列上场(408·03 章的循环队列直接抄来用):根入队;循环{出队一个、访问它、把它的左右孩子(非空)入队}直到队空。"先发现的先处理",这也是第六章 BFS 的原型。

递归遍历改非递归?手动管一个栈模拟(中序:一路向左全压栈,弹一个访问一个,再转向右子树)。408 考"用什么结构"(答:栈)和读代码,很少让你默写。

## 5.4 由遍历序列反推树(大题常客)

**核心口诀:先序第一个是根,后序最后一个是根,中序里根把左右子树劈开。**

已知先序 `A B D E C F` + 中序 `D B E A C F`,重建:

1. 先序第 1 个 = 根 A。
2. 在中序里找 A:左边 `D B E` 是左子树的中序,右边 `C F` 是右子树的中序。
3. 按人数把先序也切开:左子树先序 `B D E`,右子树先序 `C F`。
4. 对每半递归执行 1~3(又是递归!地板:序列为空)。

对左半:根 B,中序劈成 D | E……一路做完:

```
        A
       / \
      B   C
     / \    \
    D   E    F
```

**验算习惯**:建完树,亲手写出它的后序(`D E B F C A`),若题目多给了后序就核对,没给也自查中序还原。

**哪些组合能唯一定树?** 对照表(判断题弹药):

| 组合 | 能否唯一确定 | 原因 |
|---|---|---|
| 先序 + 中序 | ✓ | 中序负责劈左右 |
| 后序 + 中序 | ✓ | 同上(后序从尾巴取根) |
| 层次 + 中序 | ✓ | 层次第一个也是根 |
| **先序 + 后序** | ✗ | 只有一个孩子时,分不清它是左是右 |

## 5.5 线索二叉树:废物利用 n+1 个空指针

动机:遍历完想再找"中序下一个",还得重新遍历一遍?太亏。5.2 数过,链式二叉树有 **n+1 个空指针**闲着——把它们利用起来:**左空指针改指"遍历序列中的前驱",右空指针改指"后继"**,再给每个结点加两个标志位 `ltag/rtag`(0=正经孩子,1=线索)区分。

按哪种遍历序列穿线,就叫哪种线索二叉树(中序线索最常考)。考法两种:

1. **画图**:给树,画出中序线索化后的所有线索箭头。手法:先写出中序序列,序列里每对相邻结点之间,看前一个的右指针空不空、后一个的左指针空不空,空就连线索。
2. **找后继**:中序线索树里结点 p 的后继——若 `rtag==1` 直接顺线索走;否则(有右孩子)是**右子树里最左下的结点**。前驱对称。

## 5.6 树、森林与二叉树的互转:左孩子右兄弟

普通树每个结点孩子数不定,存储费劲。**"孩子-兄弟表示法"**一招统一:每个结点两根指针——`firstChild` 指第一个孩子,`nextSibling` 指右边的兄弟。两根指针!这不就是二叉树的壳么。于是:

**树 → 二叉树**:每个结点,左指针挂长子,右指针挂大弟。口诀"**左孩子,右兄弟**"。
**森林 → 二叉树**:每棵树先各自转,然后第 2 棵树的根挂到第 1 棵根的**右指针**上(根们互为"兄弟"),依此串下去。

画图题手法:原树里给所有兄弟之间连横线,删掉每个结点到"除长子外其余孩子"的竖线,然后把整幅图顺时针拧 45°——就是那棵二叉树。

**遍历的对应关系**(选择题背表,但理解了口诀其实能推):

| 树/森林的遍历 | 等于对应二叉树的 |
|---|---|
| 树的先根遍历 / 森林的先序 | **先序**遍历 |
| 树的后根遍历 / 森林的中序 | **中序**遍历 |

## 5.7 哈夫曼树与哈夫曼编码(大题送分,手要稳)

问题:n 个叶子各带权 w,构造二叉树使 **WPL = Σ(叶子权 × 叶子深度到根的路径长)** 最小。贪心解法:

> **每次从池子里取权值最小的两棵树,合成一棵(新根权 = 两者之和),放回池子;重复到只剩一棵。**

例:权 {2, 3, 4, 7}。
① 取 2,3 → 合成 5。池:{4, 5, 7}
② 取 4,5 → 合成 9。池:{7, 9}
③ 取 7,9 → 合成 16。完工。

```
         16
        /  \
       7    9
           / \
          4   5
             / \
            2   3
```

WPL = 7×1 + 4×2 + 2×3 + 3×3 = **30**。(**验算捷径:WPL = 所有非叶结点权值之和** = 5+9+16 = 30。合并 k 次每次的新根权都会被它下面的叶子重复计入,数学上恰好等价——考场双算法互查,稳。)

**哈夫曼编码**:往左标 0 往右标 1,每个叶子的编码 = 根到它的 01 路径。因为字符全在叶子上,任何编码都不是另一个的前缀(**前缀码**),解码无歧义。带权版就是"高频字符编短码"的最优压缩。

配套结论:哈夫曼树没有度 1 结点(每次合并都拿两个),所以 **n0 个叶子 → 总结点数 2n0 − 1**。注意哈夫曼树**不唯一**(等权可交换、左右可交换),但 **WPL 唯一**。

## 5.8 并查集(树的另一副面孔)

用途:维护"哪些元素属于同一集合",支持两个操作——`find(x)` 找 x 所在集合的代表,`union(a,b)` 合并两个集合。第六章 Kruskal 判环、判连通全靠它。

实现:一个 `parent[]` 数组,`parent[x]` = x 的父结点,根的 parent 是自己(或存负的集合大小)。find 就是顺着 parent 爬到根;union 就是把一棵树的根接到另一棵的根下面。

两个优化(408 考概念):**按秩/按大小合并**(矮树挂高树下,防止长成链)+ **路径压缩**(find 沿途结点直接改挂到根)。两者齐上,单次操作接近 O(1)(严格说 α(n),反阿克曼,当常数看)。

## 易错点

1. n0 = n2 + 1 只对**二叉树**成立;普通树用"结点数 = 边数 + 1"现推。
2. 完全二叉树编号从 1 开始公式才是 2i/2i+1;题目从 0 编号则是 2i+1/2i+2——看清再算。
3. 先序+后序不能唯一定树;但**满二叉树或无度1结点的树**可以(特例判断题)。
4. 线索二叉树找后继,rtag=0 时是"右子树最左下",不是右孩子本身。
5. 树转二叉树后,**根没有右孩子**(根无兄弟);森林转的才有。
6. 哈夫曼 WPL 算的是**叶子**的加权路径,别把内部结点也乘深度算进去(验算用"非叶权和"那条捷径互查)。
7. 高度/深度的定义各教材差 1(根算第 0 层还是第 1 层),按题目约定,别按记忆。

## 例题

**例 1** 完全二叉树有 768 个结点,求叶子数。
<details><summary>解析</summary>
n = n0+n1+n2,n0 = n2+1 → n = 2n0 − 1 + n1。768 是偶数,而 2n0−1 是奇数,所以 n1 = 1。768 = 2n0 → **n0 = 384**。(完全二叉树 n1∈{0,1},靠奇偶性定 n1——本题型的固定解法。)
</details>

**例 2** 中序 `B D C E A F H G`,后序 `D E C B H G F A`,画树并写先序。
<details><summary>解析</summary>
后序末位 A 是根;中序里 A 劈出左 `B D C E`、右 `F H G`。左子树后序 `D E C B` → 根 B,B 在左中序里劈出左空、右 `D C E`……逐层做完,先序应为 `A B C D E F G H`。做完拿中序验算。
</details>

**例 3** 权 {5, 29, 7, 8, 14, 23, 3, 11} 构造哈夫曼树,求 WPL。
<details><summary>解析</summary>
合并序列:3+5=8;7+8=15;8+11=19;14+15=29;19+23=42;29+29=58;42+58=100。WPL = 非叶权和 = 8+15+19+29+42+58+100 = **271**。
</details>
