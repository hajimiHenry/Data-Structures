# 408·第六章 图

> 图 = 结点想连谁连谁的终极自由形态。心理建设先做好:**这一章 408 几乎不考写代码,考的是"手算 + 概念辨析"**——Prim/Kruskal/Dijkstra/拓扑/关键路径全是"给图,填表,选答案"。所以本章的动手工程也以"用程序验证手算"为主。树那章的两台发动机继续服役:DFS 是先序遍历的推广,BFS 是层次遍历的推广。

## 6.0 术语速查表(选择题的弹药库)

| 术语 | 含义 | 常考数字 |
|---|---|---|
| 无向图 | 边无方向 (A,B) | 边数 = 度数总和 ÷ 2(每条边贡献 2 度) |
| 有向图 | 弧有方向 <A,B> | 每个点分**入度/出度**,弧数 = 入度和 = 出度和 |
| 完全图 | 任意两点都有边 | 无向 n(n−1)/2 条;有向 n(n−1) 条 |
| 连通(无向) | 任意两点有路 | 连通图**至少 n−1 条边**(恰好 n−1 = 树) |
| 强连通(有向) | 任意两点**互相**可达 | 强连通**至少 n 条弧**(成一个环) |
| 连通分量 | 极大连通子图 | "极大"=一个也不能再加 |
| 生成树 | 含全部 n 个顶点的极小连通子图 | 恰 n−1 条边;砍一条断,加一条成环 |
| 稠密/稀疏 | 边多/边少 | 决定存储和算法选型 |

**两个经典陷阱题**:① n 个顶点的无向图**至少几条边保证连通**?——n−1 只是"可能连通"的下限;要**保证**任何形态都连通,得 C(n−1,2)+1 条(先把 n−1 个点连成完全图还留一个孤点,是"不连通的最多边数",再加 1 条就必连)。"至少"和"保证至少"是两道不同的题。② 有向图弧 <A,B>:A 的**出**度、B 的**入**度各 +1,方向别数反。

## 6.1 存储:两大主力 + 两个认脸的

### 邻接矩阵

n×n 二维数组,`G[i][j] = 1`(或权值)表示 i→j 有边。无向图矩阵**对称**(可以只存一半——第三章压缩存储的用武之地)。

- 查 i,j 之间有没有边:O(1),这是它的绝活。
- 数 i 的邻居:扫一整行 O(n),边再少也这么贵 → **空间 O(n²),稀疏图血亏**。
- 有向图:第 i **行**之和 = i 的出度;第 i **列**之和 = 入度。
- 冷知识(考过):矩阵 A 的 k 次幂,A^k[i][j] = i 到 j **长度为 k 的路径条数**。

### 邻接表

n 个链表头:`adj[i]` 挂一条链,串着 i 的所有邻居——**"每个顶点一条自己的单链表"**,你的老本行。

- 空间 O(n + e),稀疏图省。
- 数 i 的邻居:顺链走,只花"真实邻居数"的钱。
- 查 i,j 有没有边:得遍历 i 的链,O(度)。和矩阵正好互补。
- 有向图邻接表:出度好数(链长),**入度得全表扫**——难受?于是有**逆邻接表**(链里存"谁指向我")。

| | 邻接矩阵 | 邻接表 |
|---|---|---|
| 空间 | O(n²) | O(n+e) |
| 查边 (i,j) | O(1) | O(deg(i)) |
| 遍历复杂度 | O(n²) | O(n+e) |
| 适合 | 稠密图 | 稀疏图 |
| 表示唯一吗 | 唯一 | 不唯一(链内顺序随意 → **DFS/BFS 序列也随之不唯一**,考点!) |

### 认脸即可的两个

- **十字链表**(有向图):每条弧一个结点,同时挂在"弧尾相同"链和"弧头相同"链上——出度入度都好数。就是第三章稀疏矩阵十字链表的兄弟。
- **邻接多重表**(无向图):每条边只存一份(邻接表里无向边要存两份),删边方便。

## 6.2 遍历:BFS 与 DFS

**BFS(广度优先)= 树的层次遍历推广**:队列 + 一个 `visited[]` 数组。出队访问,把**没访问过的**邻居全部入队并**入队时就标记**(等出队再标会重复入队,经典 bug)。一圈一圈向外扩散,像水波。

**DFS(深度优先)= 先序遍历推广**:递归(或手动栈)。访问 x,标记,对 x 的每个未访问邻居递归。一条路走到黑再回头。

和树遍历的唯一区别:**图有环,必须靠 `visited[]` 防止绕圈**;树没环所以不用。

- 复杂度:邻接表 O(n+e),矩阵 O(n²)(遍历时每个点都要扫一行)。
- 对**非连通图**遍历:外面套一层循环,对每个未访问顶点各发动一次 → **发动次数 = 连通分量个数**(考点:用遍历数连通分量)。
- 无权图的**单源最短路径**(按边数算)直接用 BFS——第一次碰到就是最短(水波先到)。
- DFS/BFS 序列不唯一(邻接表顺序、起点都影响),但给定邻接表则唯一——判断题措辞抠这个。

## 6.3 最小生成树 MST:Prim 与 Kruskal(手算题)

带权连通无向图中,选 n−1 条边连通所有顶点且总权最小。两种贪心,**手算都必须会**:

**Prim("长树"法)**:从任一点出发,维护一棵不断长大的树;每步从"树内点 ↔ 树外点"的所有边里挑**最短的**,把那个外点拉进树。走 n−1 步。——像滚雪球,适合**稠密图**,O(n²)(与边数无关)。

**Kruskal("捡边"法)**:把所有边按权**从小到大排序**,依次捡:这条边的两端**已在同一棵树里就跳过(成环)**,否则要它。捡满 n−1 条收工。判"同一棵树"用什么?——**并查集**(5.8 的伏笔在此兑现)。适合**稀疏图**,O(e log e)。

手算 Kruskal 时判环别犯懒:在纸上给顶点分组(集合),捡一条边就合并两组,两端同组的边划掉。

**结论题弹药**:各边权互不相同 → MST **唯一**;有等权边 → MST 可能不唯一,但**总权值必唯一**。MST 里"任意割(把顶点分两半)的最短跨割边"必在某棵 MST 中——Prim/Kruskal 正确性的根基,理解即可。

## 6.4 最短路径:Dijkstra 与 Floyd(填表题)

### Dijkstra:单源最短路,贪心逐个"敲定"

维护 `dist[]`(源到各点当前最短距离)和"已敲定"集合 S。每轮:

1. 从**未敲定**的点里挑 dist 最小的 u,敲定它(它不可能再被绕路优化——前提:**无负权边**)。
2. 用 u **松弛**邻居:若 `dist[u] + w(u,v) < dist[v]`,更新 dist[v](顺手记 v 的前驱,用于回溯路径)。

**手算就是填表**:一行一轮,列是各顶点的 dist,每轮圈出敲定的点。练两遍就顺。O(n²)。

⚠ **有负权边就失效**(先敲定的可能被后来的负边翻案)——408 判断题常青树。

### Floyd:全源最短路,三重循环的动态规划

```c
for (k = 0; k < n; k++)          // 允许经过的"中转站"逐个开放
  for (i = 0; i < n; i++)
    for (j = 0; j < n; j++)
      if (d[i][k] + d[k][j] < d[i][j]) d[i][j] = d[i][k] + d[k][j];
```

从邻接矩阵出发,k 每加一个,矩阵更新一轮。**k 必须在最外层**(先固定中转站集合,再全表松弛)。O(n³),代码五行,手算考"k 开放到某一步时的矩阵"。能处理负权边,**不能有负权回路**。

| | Dijkstra | Floyd | BFS |
|---|---|---|---|
| 解什么 | 单源 | 全源(所有点对) | 单源(无权图) |
| 负权边 | ✗ | ✓(负环 ✗) | — |
| 复杂度 | O(n²) | O(n³) | O(n+e) |

## 6.5 拓扑排序(AOV 网)

顶点表示活动、弧表示先后约束(<A,B> = A 得先干)的有向图叫 **AOV 网**。拓扑排序 = 给所有活动排一个不违反约束的次序:

> **反复摘"入度为 0"的顶点**:摘一个输出一个,它指向的各点入度 −1(可能诞生新的 0),用栈或队列存"当前入度 0 的点"。

- **输出不满 n 个就卡住了 → 图有环**(环上的点入度永远清不到 0)。这是判环的标准办法之一(另一个:DFS 遇到"正在访问中"的点)。
- 拓扑序**一般不唯一**(同时有多个入度 0 时任选)。何时唯一?任意相邻两点都有约束时(比如本身就是一条链)。
- 逆拓扑排序:反复摘**出度**为 0 的点;或者:**DFS 的退栈顺序(结束顺序)恰好是逆拓扑序**——选择题考过,值得记。

## 6.6 关键路径(AOE 网)——大题填表的巅峰

弧表示活动(带权=耗时)、顶点表示事件(里程碑)的图叫 **AOE 网**。求:整个工程最短工期,以及哪些活动**一天都不能拖**(关键活动)。手算四步,顺序固定:

1. **事件最早发生时间 ve**:按**拓扑序**推。源点 ve=0;`ve(v) = max{ ve(u) + w(u→v) }`(所有进来的弧取 **max**——所有前置全完工才算到)。汇点的 ve = **总工期**。
2. **事件最迟发生时间 vl**:按**逆拓扑序**推。汇点 vl = 它的 ve;`vl(u) = min{ vl(v) − w(u→v) }`(所有出去的弧取 **min**——不能耽误任何后续)。
3. **活动最早开始 e**:活动 a = 弧 u→v,`e(a) = ve(u)`(前置事件一到就能开工)。
4. **活动最迟开始 l**:`l(a) = vl(v) − w(a)`(掐着 deadline 倒推)。

**关键活动:e(a) == l(a)(时间余量 d = l − e 为 0)**。关键活动串成的源→汇路径 = 关键路径(可能不止一条)。

结论题:缩短关键活动能缩短工期,但**缩过头它可能不再关键**(别的路径变成瓶颈);若有多条关键路径,必须缩**所有关键路径共用**的活动才有效。

## 易错点

1. BFS 邻居要**入队时标记**,不是出队时——否则同一点重复入队。
2. Dijkstra 负权失效;Floyd 负环失效;两个"失效"别张冠李戴。
3. Prim 复杂度只看 n(O(n²)),Kruskal 看 e——"边很多用 Prim,边很少用 Kruskal"。
4. ve 取 max、vl 取 min,方向反了全表报废——记"最早=等最慢的前置(max),最迟=迁就最急的后续(min)"。
5. 邻接表的 DFS/BFS 序列不唯一;矩阵存储 + 固定起点 + 按编号升序访问 → 唯一。
6. "连通图至少 n−1 条边" vs "保证连通至少 C(n−1,2)+1 条",审题看有没有"保证"。

**例 2** 用 Kruskal 求 MST:边集 (A,B,4) (A,C,1) (B,C,2) (B,D,5) (C,D,8) (C,E,10) (D,E,2)。

</details>

**例 3** Dijkstra 从 A 出发:A→B 10, A→C 3, C→B 4, B→D 2, C→D 8, D→E 6, C→E 12。填每轮的 dist 表。
<details><summary>解析</summary>
